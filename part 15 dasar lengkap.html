Cara Membuat Daftar/List di HTML (ol, ul, dan li tag)

Tag <ol> digunakan untuk membuat daftar berurutan (ordered list), tag <ul> untuk daftar tidak berurutan (unordered list), dan tag <li> digunakan untuk setiap item dalam daftar.

Contoh Daftar Tontonan Anime bulan Juni (Unordered List)

  • Wind Breaker
  • One Piece
  • Demon Slayer

Contoh Daftar Tontonan Anime bulan Juni (Ordered List)

  1. Wind Breaker
  2. One Piece
  3. Demon Slayer

4. Cara Menambahkan Gambar di HTML (img tag)

Tag <img> digunakan untuk menambahkan gambar di halaman HTML. Atribut src menentukan alamat gambar, dan alt memberikan deskripsi alternatif jika gambar tidak dapat ditampilkan.

5. Cara Membuat Link di HTML(a tag)

Tag <a> digunakan untuk membuat tautan (link) di HTML. Atribut href menentukan alamat tujuan tautan tersebut. Klik tautan untuk membuka halaman atau sumber lain.

Contoh link: Kunjungi Google

6. Cara Membuat Tabel di HTML (table tag)

Tag <table> digunakan untuk membuat tabel di HTML. Tabel terdiri dari baris <tr>, header kolom <th>, dan sel data <td>.

7. Cara Membuat Komentar di HTML

Komentar di HTML digunakan untuk menyisipkan catatan atau penjelasan dalam kode yang tidak akan ditampilkan di browser.
Komentar dapat membantu pengembang memahami kode dengan lebih baik.

8. Cara Membuat Form di HTML (form tag)

Tag <form> digunakan untuk membuat form di HTML yang memungkinkan pengguna memasukkan data. Form biasanya memiliki elemen input, label, dan tombol submit.
